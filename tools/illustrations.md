## Playful extras

Added on 2026-10-18 by `tools/build_fun.py` (and `tools/build_tag.py` for the one piece that needs live data). All four pieces are hand-written, script-free SVG in the same paper-and-ink palette, so they animate inside a GitHub README without any external service:

- `assets/journey-board.svg` — the station departure board. Four services (233 次开往下一个坑, 0 次开往早睡, 404 次开往灵感, Git 号开往线上) flip between playful statuses on independent loops inside split-flap panels. Statuses are colour-coded — green for on time, red for delays and cancellations, ochre for work in progress. The clock colon blinks and an announcement ticker scrolls underneath.
- `assets/journey-cat.svg` — 值班站长三花, the station-master cat in a red cap with a gold star badge, red collar, swinging bell and waving flag. She swishes her tail, twitches an ear, blinks, and a speech bubble cycles through five short messages while two gold paper cranes drift across the card.
- `assets/stamp-*.svg` — four collectible rubber stamps, one per project, in four ink colours and four tilts. Each carries the `途中下車` mark, a grainy ink texture, its own little emblem (paper crane, gear, key, house) and the project's star count on the lower arc, or `新站` while it is still fresh. The README wraps each one in a link to its repository.
- `assets/journey-tag.svg` — a baggage tag (passenger 日天, seat 233, departed 2022.09) carrying repository, follower and star counts, a barcode derived from the login, a `请勿倒放` mark and a tear-off perforation. `tools/build_tag.py` refreshes the tag numbers and the stamp star counts, and the daily workflow commits the result; when the API is unreachable the previous numbers are kept.

## Cover edit prompt

Use case: precise-object-edit. Edit target: existing wide illustrated GitHub profile cover. Remove ALL lettering from the image: the large Chinese title at top left, the Japanese phrase underneath, and the small username near bottom left. Seamlessly reconstruct the blue sky, sunlit clouds and sea behind every removed letter. Keep the girl, her face, red clothes, train windows, train curving across the sea, golden sunset, cranes, painterly anime linework and original composition unchanged. Output same wide panoramic aspect ratio. Absolutely no text, lettering, logo or watermark anywhere.

Input: `assets/chihiro-japanese-v2.png`. Output: `assets/chihiro-cover-no-text.png`.
